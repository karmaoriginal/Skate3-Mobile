SEIYU PARADISE PENGUIN MOD v1.0.0

Skate 3 Mobile players should install this mod from the Mod Store in the app.

Manual installation:
1. Open the Skate 3 Mobile launcher.
2. Open Characters (or Restore Seiyu) > Import archive.
3. Select this ZIP file (.zip, .rar, .7z, .tar and .tar.gz also work).
4. Start the game and open RB + Start > Mods > Playable Character.
5. Select Seiyu Paradise Penguin.

On older builds without the archive importer:
1. Open Characters > Restore Seiyu > Choose files.
2. Select base.obj first, texture_diffuse.png second.
3. Start the game and open RB + Start > Mods > Playable Character.

The original skater remains available. No Skate 3 retail game data is included.
